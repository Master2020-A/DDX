# Assets para la Aplicación Móvil

## Iconos Requeridos

Para que la aplicación compile correctamente, necesitas los siguientes archivos de imagen:

### 1. icon.png
- **Tamaño:** 1024x1024 px
- **Formato:** PNG con transparencia
- **Uso:** Icono principal de la app

### 2. splash.png
- **Tamaño:** 1284x2778 px (iPhone 13 Pro Max)
- **Formato:** PNG
- **Uso:** Pantalla de carga

### 3. adaptive-icon.png (Android)
- **Tamaño:** 1024x1024 px
- **Formato:** PNG con transparencia
- **Uso:** Icono adaptativo de Android

### 4. favicon.png (Web)
- **Tamaño:** 48x48 px
- **Formato:** PNG
- **Uso:** Favicon para versión web

## Cómo Crear los Iconos

### Opción 1: Usar un Logo Existente
Si tienes un logo de DDX, redimensiónalo a los tamaños requeridos.

### Opción 2: Crear Iconos Temporales
Puedes usar iconos temporales para desarrollo y reemplazarlos después.

### Opción 3: Generadores Online
- https://www.appicon.co/
- https://icon.kitchen/
- https://makeappicon.com/

## Colores de DDX
- **Primario:** #4F46E5 (Indigo)
- **Secundario:** #0EA5E9 (Sky Blue)
- **Acento:** #06B6D4 (Cyan)

## Nota
Los archivos de imagen NO están incluidos en el repositorio por defecto.
Debes crearlos antes de compilar la aplicación.
